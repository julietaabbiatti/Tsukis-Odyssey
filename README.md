Tsuki's Odyssey - Web Hub

Proyecto desarrollado para la materia Programación IV de la Tecnicatura Universitaria en Programación (UTN) a cargo del profesor Mariano Ingerto.
Este sitio web es una plataforma interactiva y completamente responsiva dedicada al popular juego de dispositivos móviles "Tsuki's Odyssey" y al estudio desarrollador HyperBeard. El proyecto fue construido desde cero cumpliendo con todos los requerimientos técnicos de la cursada, enfocándose en un diseño fluido, código limpio y manipulación del DOM.

Características principales y Requerimientos Cumplidos
- Navegación estructurada:Menú principal con 6 enlaces de primer nivel y un menú desplegable (dropdown) con 3 submenús.
- Galería interactiva: Sistema de grilla (Mosaico) con imágenes que se amplían mediante ventanas modales dinámicas.
- Sección de Personajes y Ayuda:Tarjetas informativas generadas e integradas con el diseño general.
- Formulario de Contacto: Formulario completamente funcional e interactivo.
- Diseño 100% Responsivo: Adaptación a todos los dispositivos móviles y tablets utilizando Flexbox, CSS Grid y Media Queries.
- Animaciones y UX: Efectos de scroll progresivo (Intersection Observer), transiciones CSS, fondos animados y menús adaptativos.

Tecnologías utilizadas
- HTML5 (Estructura semántica)
- CSS3 (Flexbox, Grid, Animaciones, Variables)
- JavaScript Vanilla (Manipulación del DOM, Event listeners, Lógica de Modales)
- Git & GitHub (Control de versiones y despliegue)
